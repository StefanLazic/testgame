# Documentation rules for agents

These rules apply to anyone (human or AI agent) changing Claw Defense.

## Keep the character docs in sync

The character documentation is generated by hand from
[`js/config.js`](../js/config.js) and must never drift from the code.

**Whenever a cat (tower) is added, removed, renamed or rebalanced** — i.e. any
change to `TOWERS`, `TOWER_ORDER`, `MAX_LEVEL`, `upgradeCost` or `towerStats`
in `js/config.js`, or to a cat's behaviour in `js/game.js` — you **must** update
[`docs/cats.md`](cats.md) in the same change:

- the stat table (cost, damage, range, fire rate, targeting, special)
- the per-cat description
- the upgrade formulas, if they changed
- the shared mechanics section, if the behaviour changed

**Whenever an enemy is added, removed, renamed or rebalanced** — i.e. any change
to `ENEMIES`, `WAVES`, `hpScale` or `waveBonus` in `js/config.js`, or to enemy
behaviour (armour, leaks, flying, boss abilities, drops) in `js/game.js` — you
**must** update [`docs/enemies.md`](enemies.md) in the same change:

- the roster table (HP, speed, bounty, armour, lives lost, flying)
- the per-enemy description
- boss abilities (howl, spawner, enrage) and shared mechanics
- the wave table

If a change affects both cats and enemies (for example a new damage or armour
rule), update **both** files.

## Also check

- `README.md` — it summarises the five cats and the pests; update it if the
  roster changes.
- Keep the docs consistent with the values in `js/config.js`; that file is the
  single source of truth for balance.

## Bump the version on every pull request

The game version lives in [`js/version.js`](../js/version.js) and is shown on
the title screen. Every pull request — human or AI agent — **must** bump it:

- patch (`1.0.0` → `1.0.1`) for fixes, docs, tests and small tweaks
- minor (`1.0.1` → `1.1.0`) for new cats, enemies, maps or features
- major (`1.1.0` → `2.0.0`) for a reworked game

Keep the `version` field in `package.json` identical to `VERSION`;
`tests/unit/version.test.js` fails if the two drift apart.
